# Contributing

Use Python 3.9-compatible syntax, keep changes scoped, and add tests for every behaviour change. Run `make lint`, `make type`, and `make test` before opening a change. Do not commit raw provider caches, FIA PDFs, model weights, secrets, or generated run directories. Research changes must follow `research/PROTOCOL.md`; never select a model using previously examined 2026 results and describe it as independent evidence.
